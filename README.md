# BookStoreApp

## 📱 소개
**BookStoreApp**은 사용자가 원하는 책을 검색하고, 해당 책의 정보를 확인하거나 저장할 수 있는 앱입니다.
MVC 패턴을 기반으로 설계되었으며, **CoreData**를 활용하여 로컬 데이터베이스에 책 정보를 저장하며, 외부 API(Kakao API)를 이용해 책 데이터를 가져와 사용자에게 제공합니다.
또한 최근 본 책 목록을 기록하여 다시 확인할 수 있는 기능을 제공합니다.

## ⚙️ 주요 기능
- **책 검색**: 사용자가 입력한 키워드를 기반으로 API를 활용하여 책을 검색합니다.
-	**상세 정보 보기**: 검색한 책의 상세 정보를 모달창으로 확인할 수 있습니다.
-	**책 담기**: 원하는 책을 코어데이터에 저장하여 나중에 확인할 수 있습니다.
-	**최근 본 책 기록**: 사용자가 조회한 책을 기록하여 최근 본 책 목록에 표시합니다.
-	**UI 구성**: 검색 결과는 CollectionView로 표시되며, 사용자가 직관적으로 정보를 확인할 수 있도록 설계되었습니다.

## 💿 버전
- 언어 : **Swift 5**
- 버전 : **Xcode 16.1**
- 아키텍처 : **MVVM (Model-View-ViewModel)**
- 외부 API : **Kakao API**

## 🛠️ 사용 기술
- **UIKit**: 사용자 인터페이스 설계(UI 구현)
- **CoreData**: 데이터의 로컬 저장 및 관리
- **Alamofire**: 네트워킹 및 API 호출
- **SnapKit**: UI 레이아웃 작성의 간결화
- **RxSwift**: 비동기 작업 및 데이터 바인딩을 간편하게 처리하기 위해 사용
- **Kingfisher**: 외부 API에서 가져온 책 이미지를 효율적으로 다운로드 및 캐싱 처리

## 🖥️ 주요 화면

- 검색 화면: 책 검색 및 검색 결과를 표시하는 화면
-	최근 본 책 화면: 사용자가 최근에 조회한 책 목록을 표시하는 화면
-	상세 정보 화면: 선택한 책의 상세 정보를 보여주는 모달 창
- 담긴 책 리스트 화면: 사용자가 저장한 책들을 리스트로 표시하는 화면
